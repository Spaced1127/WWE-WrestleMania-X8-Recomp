## Launcher artwork

Downloaded from [SteamGridDB](https://www.steamgriddb.com), game entry
*WWE WrestleMania X8* (id 5295541). The artwork is promotional art, not data
extracted from the game disc, and remains the property of its respective
owners.

| Asset | Artist |
|---|---|
| Icon 1024x1024 | Macho Sadness |
| Hero 3840x1240 | Macho Sadness |
| Logo 1280x720 | Macho Sadness |
| Grid 600x900 | Just.Seani |

Original files: `art/steamgriddb/`. The launcher embeds the icon in the
executable and ships a blurred derivative of the hero as
`resources/background.png`.

## Game

*WWE WrestleMania X8* is a GameCube title published by THQ and developed by
Yuke's. This project ships no game data; the player supplies their own disc.
